# Layered Mini Maker — BerkayMakes

Forge 2.5D layered pixel-art tabletop miniatures in the browser: a base-colour slab, raised colour layers, an optional coloured back, a tab and a slotted round base. It comes with a pixel editor for drawing the front and back.

**Open it:** https://berkayra.github.io/berkaymakes-mini-maker/

## On the iPhone

1. Open the link above in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open it once from the new icon while online; after that it also works offline.

**From Photos** (next to each Upload / Open button) opens the photo library.
